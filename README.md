# Конструктор имени из пухлых букв

3D-конструктор: покупатель вводит имя, красит буквы, выбирает высоту, поверхность и декор, видит цену и кладёт заказ в корзину.

- `constructor.js` — виджет (цены, палитра и размеры — в блоке «НАСТРОЙКИ» в начале файла)
- `shapes/` — 3D-модели букв, цифр и декора
- `index.html` — демо-страница

## Вставка на сайт (Тильда — блок T123 «HTML-код»)

```html
<div id="letters-constructor"></div>
<script type="module" src="https://ЛОГИН.github.io/letters-constructor/constructor.js"></script>
```

`ЛОГИН` — имя аккаунта на GitHub. Модели подгружаются из `shapes/` рядом с `constructor.js`.
