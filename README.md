# Конструктор имени из пухлых букв

3D-конструктор. Покупатель вводит имя, красит буквы, выбирает высоту, поверхность и декор, видит цену и кладёт заказ в корзину.

## Что внутри

- `constructor.js` — сам виджет. Цены, палитра и размеры задаются в блоке «НАСТРОЙКИ» в начале файла.
- `index.html` — демо-страница.
- `shapes/` — 3D-модели, всего 75 файлов:
  - `ru_01` … `ru_33` — русские буквы А–Я, включая Ё. Плюс `ru_16h` — «О» с сердечком;
  - `la_A` … `la_Z` — латинские буквы. Плюс `la_Oh` — «O» с сердечком;
  - `d0` … `d9` — цифры;
  - `star`, `heart`, `cone_body` и `cone_stripes` — декор: звёздочка, сердечко и конус (корпус и полосы).

## Вставка на сайт (Тильда, блок T123 «HTML-код»)

```html
<div id="letters-constructor"></div>
<script type="module" src="https://eizhidok.github.io/letters-constructor/constructor.js"></script>
```

Модели подгружаются из папки `shapes/`, которая лежит рядом с `constructor.js`.
